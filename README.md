
# 📈 SahamIn

### Website Informasi & Analisis Saham Indonesia 🇮🇩

SahamIn adalah platform sederhana untuk membantu investor mendapatkan informasi saham Indonesia dengan lebih mudah.

## 🚀 Fitur

- 📊 Informasi saham Indonesia
- 📈 Analisis pergerakan saham
- 📰 Berita pasar saham
- 🧮 Kalkulator average saham
- 💰 Kalkulator profit & loss
- 🔎 Pencarian kode saham

## 🎯 Tujuan

Membantu investor memahami pasar saham Indonesia dengan informasi yang sederhana, mudah dipahami, dan praktis.
